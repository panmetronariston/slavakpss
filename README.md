# Слава КПСС: стилометрия

Проект проверяет методами [стилометрии](https://sysblok.ru/knowhow/stilometrija-kak-v-raznoe-vremja-ljudi-iskali-avtorov-tekstov/),
есть ли у Славы КПСС (и его альтер-эго: Гнойный, Соня Мармеладова, Валентин Дядька)
устойчивый «авторский почерк». Ещё он позволяет проверить, похож ли произвольный рэп-текст на его стиль.

```
Genius ──(Python, lyricsgenius)──► data/raw/*.jsonl
        ──(фильтр партий по [Куплет: …])──► corpus/{songs,chunks,personas}/*.txt
        ──(R, stylo)──► app/data/corpus.rds ──► веб-приложение (Shiny)
                     └► results/ (графики stylo, Zeta, кросс-валидация)
```

## Структура

| Путь | Что делает |
|---|---|
| `config/artists.json` | кого скачивать: имена на Genius, псевдонимы в заголовках секций, альтер-эго Славы, рэперы для сравнения |
| `scraper/collect.py` | скачивает тексты с Genius (можно перезапускать: уже скачанное пропускается) |
| `scraper/lyrics.py` | разбирает разметку Genius и оставляет только партии нужного исполнителя |
| `scraper/build_corpus.py` | собирает корпус в формате stylo (`Автор_название.txt`) |
| `analysis/prepare.R` | токенизирует корпус через `stylo` и сохраняет `app/data/corpus.rds` |
| `analysis/run_stylo.R` | классический прогон `stylo()` (CA, MDS, BCT), оценка точности, Craig's Zeta, калибровка imposters |
| `app/` | веб-приложение на Shiny |

## Как выделяются партии Славы

На Genius текст размечен заголовками: `[Куплет 1: Слава КПСС]`, `[Припев: Слава КПСС & Замай]`, `[Интро]`.

* Секция берётся, если в заголовке указан Слава или одно из его альтер-эго (список в `config/artists.json → target.personas`).
* По умолчанию (`--mode solo`) совместные секции (`Слава КПСС & Замай`) **не** берутся: в них непонятно, чьи строки. С `--mode any` они включаются.
* Секции без имени (`[Припев]`) приписываются основному исполнителю, но только в сольной песне. Если в песне есть гости, такие секции отбрасываются.
* Повторы припевов убираются (иначе они раздувают частоты). Текст в скобках (эдлибы, бэк-вокал) тоже убирается. «ё» заменяется на «е».
* Интервью, трек-листы, ремиксы и лайвы пропускаются. Баттлы по умолчанию тоже пропускаются, их можно включить флагом `--include-battles`.
* Одна песня содержит 200–400 слов, а это мало для стилометрии. Поэтому корпус дополнительно склеивается в куски примерно по 1500 слов (`corpus/chunks`).

Партии других рэперов выделяются так же, по их псевдонимам. Поэтому из фита «Замай feat. Слава КПСС»
куплет Славы попадёт к Славе, а куплет Замая к Замаю.

## Запуск

### 1. Сбор текстов (Python ≥ 3.9)

```bash
pip install -r requirements.txt
export GENIUS_ACCESS_TOKEN=...        # https://genius.com/api-clients → Generate Access Token
python -m scraper.collect --max-songs 150          # все из конфига
python -m scraper.collect --skip-reference         # только Слава и альтер-эго
python -m scraper.build_corpus                     # → corpus/
python -m pytest tests                             # тесты фильтрации
```

Перед сбором проверьте `config/artists.json`: имена на Genius, список альтер-эго и набор рэперов для сравнения.
Если Genius вернёт не того артиста, `collect.py` предупредит об этом в логе. Если Genius
блокирует запросы (403 / Cloudflare), запустите сбор с домашнего IP или поставьте большую паузу через `sleep_time`.

### 2. Анализ в R (≥ 4.1)

```r
source("install.R")    # stylo, shiny, bslib, DT, ggplot2, ape, e1071
```

```bash
Rscript analysis/run_stylo.R   # необязательно, но даёт Zeta-слова и калибровку порогов
Rscript analysis/prepare.R     # обязательно для приложения
```

`stylo` требует Tcl/Tk. На Linux поставьте `tcl tk`, на Windows и macOS они уже идут вместе с R.

### 3. Веб-приложение

```r
shiny::runApp("app")
```

Вкладки:

* **Корпус**: сколько песен и слов у каждого автора и альтер-эго, а также таблица песен со ссылками на Genius.
* **Частые слова**: самые частотные слова автора или альтер-эго. Отдельно показаны характерные слова Славы по сравнению с другими рэперами (Craig's Zeta из `stylo::oppose` или log-ratio).
* **Стилометрия**: кластерный анализ, MDS, PCA и bootstrap consensus tree. Параметры: MFW, culling, вид Delta, признаки (слова, биграммы, символьные n-граммы), набор авторов. Можно сравнить альтер-эго Славы между собой.
* **Проверка текста**: вставьте текст или загрузите `.txt`. Приложение посчитает:
  * **General Imposters** (`stylo::imposters`) для каждого автора: оценку 0…1 и серую зону `p1–p2`;
  * среднее расстояние **Delta** до текстов каждого автора и 10 ближайших текстов;
  * предсказание **SVM** (`stylo::classify`);
  * положение текста на карте MDS среди корпуса.

  Если проверяемая песня уже есть в корпусе, совпадающие тексты автоматически исключаются из сравнения.

### 4. Публикация

* **shinyapps.io** (бесплатный тариф):
  ```r
  rsconnect::setAccountInfo(name = "...", token = "...", secret = "...")
  rsconnect::deployApp("app")
  ```
* **Docker** (подходит, например, для Hugging Face Spaces, Render или своего сервера):
  ```bash
  docker build -t slavakpss . && docker run -p 3838:3838 slavakpss
  ```

`app/data/` и `corpus/` внесены в `.gitignore`, потому что тексты песен защищены авторским правом.
При деплое через `rsconnect` или Docker они берутся с локального диска, коммитить их не нужно.

## Ограничения метода

* Для надёжной атрибуции нужны тысячи слов. Вердикт по одной песне стоит считать ориентиром.
* Imposters отвечает на вопрос «похож ли текст на Славу больше, чем на рэперов из корпуса». От выбора конкурентов зависит результат, поэтому в корпус стоит добавить стилистически близких авторов.
* Разметку партий на Genius делают пользователи, и в ней бывают ошибки. Тексты рэперов, кроме того, пишутся в соавторстве и с гострайтерами.
